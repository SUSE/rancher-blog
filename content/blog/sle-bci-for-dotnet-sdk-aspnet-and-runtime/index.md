## New Base Container Images

We have another great addition to our Base Container Images (BCI) catalog!

The .NET 6.0 container images are now available. You can find the runtime image and the two separate SDKs. One is for dotnet and the other for aspnet.

Please, give those a try and let us have your feedback!

```
docker pull registry.suse.com/bci/dotnet-sdk:6.0
docker pull registry.suse.com/bci/dotnet-aspnet:6.0
docker pull registry.suse.com/bci/dotnet-runtime:6.0
```

For more information about BCI, please check out our previous announcement: <https://community.suse.com/posts/17842991>.
